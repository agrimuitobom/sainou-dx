# 配布用ファイルの置き場所

ダウンロードして使ってもらうファイル（FileMaker ソリューション、テンプレート類）をここに置きます。
発表ポスターなどの PDF は `../docs/` へ。

## 置きかた

1. このフォルダで **Add file → Upload files**
2. ファイルをドラッグして **Commit changes**
3. 公開 URL は `https://agrimuitobom.github.io/sainou-dx/assets/files/ファイル名` になります
4. その URL を Issue の「リンクを追加する」に貼れば、リンク集のカードになります

## 公開前に確認すること

ここに置いたファイルは、**誰でもダウンロードできる状態**になります。

- FileMaker（.fmp12）や表計算ファイルは、中のレコードごと公開されます。**データを空にしたコピー**を置いてください
- FileMaker は削除したレコードの跡がファイル内に残ることがあります。
  **［ファイル］→［名前を付けて保存］→「圧縮されたコピー（小さくする）」** で保存し直すと取り除けます
- オブジェクトフィールドに写真や PDF が残っていないかも確認してください
- 1 ファイル 100MB まで。動画は YouTube などに上げてリンクを貼るほうが確実です
